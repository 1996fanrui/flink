## PR Body

```
## What is the purpose of the change

When the delivery of a filtered buffer fails, `FilteringHandler#recoverWithFiltering` recycles
a buffer that the input channel already owns, corrupting its reference count.

## Brief change log

  - The compensating loop in the catch block starts at `i + 1`: `onRecoveredStateBuffer()` takes
    over the buffer at index `i` before anything can fail.

## Verifying this change

This change added tests and can be verified as follows:

  - Added `InputChannelRecoveredStateHandlerTest#testFilteredBuffersRecycledOnceWhenDeliveryFails`,
    which fails the delivery of the first filtered buffer and asserts that only the undelivered
    buffers are recycled.
```
