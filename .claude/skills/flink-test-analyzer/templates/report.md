# Report Format Reference

> This file documents the expected report structure generated by `generate_report.py`.
> It is a reference template, not used directly by the script.
> Two files are generated: `report.md` (summary) and `failure_details.md` (failure details).

## report.md

# Test Report

## Summary

- **Commit**: `{commit_hash}` (`{branch_name}`)
- **Test Request**: {test_request_description}
- **Total Iterations**: {total_iterations}
- **Overall Success Rate**: {success_rate}%

## Coarse-Grained Statistics (per iteration)

| Metric | Count |
|--------|-------|
| Total Iterations | {total} |
| Fully Successful | {success} |
| Partially Failed | {partial} |
| Success Rate | {rate}% |

## Fine-Grained Statistics (per test case)

> Only test cases with failures are listed. Successfully passed test cases are included in the total count.

| Test Class | Method | Parameters | Total | Passed | Failed | Failure Rate |
|------------|--------|------------|-------|--------|--------|--------------|
| {class} | {method} | {params} | {total} | {pass} | {fail} | {rate}% |

*Total: {X} unique test cases ({Y} always passed, {Z} had failures)*

> See failure_details.md for complete failure information including stack traces.

## Quick Failure Location

Use the following command to quickly locate failures in log files:
```bash
awk '/\[ERROR\] Errors:/{if(!found) print "---"; found=1} found{print FILENAME": "$0} /Tests run:/{if(found) found=0}' ./202*.log
```
